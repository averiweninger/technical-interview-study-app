# UI primitives

`components.json` configures shadcn/ui with the `@/` alias and Tailwind CSS variables. The Button adapts the [shadcn/ui Button](https://ui.shadcn.com/docs/components/radix/button) using Radix Slot and class-variance-authority. Its source is owned by this repository and can be edited directly. Card follows the same composable surface pattern. Progress uses the native HTML element to keep this frontend small and accessible.
